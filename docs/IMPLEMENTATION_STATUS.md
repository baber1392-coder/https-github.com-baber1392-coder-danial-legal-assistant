# وضعیت پیاده‌سازی دستیار جامع اختصاصی دانیال

## پیاده‌سازی‌شده در این نسخه
- ورود با Supabase Auth و نشست مبتنی بر کوکی SSR
- بازیابی و تغییر گذرواژه از طریق لینک تأیید ایمیل
- محافظت مسیر داشبورد؛ در نبود تنظیمات احراز هویت، مسیر خصوصی fail-closed است
- دریافت عضویت فعال دفتر و اعمال محدوده دفتر در queryهای برنامه
- داشبورد با آمار واقعی از پایگاه داده
- ایجاد، ویرایش و فهرست پرونده‌ها، موکلان، مواعد، منابع پژوهشی و گردش‌های مالی
- بارگذاری اسناد در bucket خصوصی، ثبت metadata و دریافت لینک امضاشده کوتاه‌مدت
- منطقه زمانی تهران برای ثبت و نمایش مواعد
- health endpoint مستقل از ورود کاربر
- CI شامل نصب وابستگی‌ها، typecheck و production build
- تنظیم Blueprint برای شاخه main و منطقه Frankfurt

## پایگاه داده
پروژه عملیاتی: `jwhyeohqolabcbuwhfon`، منطقه `eu-central-1`.
RLS روی تمام جداول عمومی فعال است. bucket اسناد خصوصی است. سیاست‌های عضویت دفتر برای خواندن و نوشتن رکوردها و فایل‌ها استفاده می‌شوند.

## موارد باقی‌مانده
- فعال‌سازی قابلیت Leaked Password Protection در تنظیمات Auth پروژه Supabase
- آزمون end-to-end با حساب کاربری واقعی و ایمیل بازیابی، پس از استقرار
- تکمیل CRUD طرفین پرونده، رویدادهای دادرسی و پیوست‌های چندگانه
- گردش‌کار دعوت و مدیریت نقش اعضا
- پژوهش خودکار متصل به منابع رسمی و ذخیره مشخصات بازیابی
- اتصال‌های بیرونی Gmail/Dropbox/Firecrawl در لایه وب‌اپ و مجوزهای مجزا
- خصوصی‌سازی مخزن GitHub؛ در حال حاضر مخزن عمومی است و باید از Dashboard GitHub تغییر وضعیت داده شود
- تنظیم آیکون و آزمون نصب PWA روی تلفن همراه
