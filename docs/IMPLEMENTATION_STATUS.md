# وضعیت پیاده‌سازی

## انجام‌شده در شاخه rebuild/nextjs-foundation
- پایه Next.js 15 با TypeScript و Tailwind
- رابط فارسی RTL و واکنش‌گرا
- پوسته داشبورد و نقشه ماژول‌های دفتر
- ورود با Supabase Auth و SSR cookie handling
- middleware برای محافظت مسیر داشبورد
- خروج امن از حساب
- PWA manifest پایه
- نمونه متغیرهای محیطی بدون secret
- Blueprint اولیه Render

## مسدود یا نیازمند تأیید فنی
- پروژه Supabase اصلی با ref برابر czooljntjukvkllltkmf در زمان بررسی INACTIVE بود و خواندن schema با خطای عدم دسترسی پایگاه داده مواجه شد.
- تا زمان فعال‌سازی پروژه و بررسی ساختار واقعی، migration یا query داده‌های پرونده اعمال نشده است.
- Workspace رندر در نشست ابزار انتخاب نشده است؛ ایجاد سرویس بدون انتخاب Workspace مجاز نیست.
- build و typecheck در محیط CI اجرا نشده‌اند؛ وضعیت آن‌ها تأییدنشده است.

## گام‌های بعدی
1. فعال‌سازی پروژه اصلی Supabase و بررسی جداول، migrationها، RLS و Storage.
2. تطبیق مدل داده با schema واقعی و افزودن migrationهای غیرمخرب.
3. تکمیل CRUD پرونده، موکل، سند و موعد با محدودیت office_id.
4. اتصال پژوهش حقوقی و Firecrawl با ثبت منبع و زمان بازیابی.
5. آزمون build، احراز هویت، دسترسی بین‌دفتر و آپلود سند.
6. انتخاب Workspace Render، ایجاد سرویس، تنظیم متغیرها و استقرار آزمایشی.
