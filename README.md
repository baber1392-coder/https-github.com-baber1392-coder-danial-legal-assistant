# دستیار جامع اختصاصی دانیال

سامانه وب فارسی و راست‌چین برای مدیریت دفتر وکالت ایران.

## وضعیت این شاخه
این شاخه، پایه فنی Next.js 15 و اتصال امن Supabase SSR را فراهم می‌کند. داشبورد اولیه، مسیر ورود، خروج و پوسته ماژول‌ها پیاده‌سازی شده‌اند. اتصال عملیاتی داده‌ها، نقش‌ها و سیاست‌های RLS پس از فعال شدن و ممیزی پروژه Supabase اصلی تکمیل می‌شود.

## اجرا
1. Node.js نسخه 20 یا بالاتر نصب کنید.
2. `npm install`
3. فایل `.env.example` را به `.env.local` کپی کنید و مقادیر واقعی Supabase را در محیط محلی یا Render تنظیم کنید.
4. `npm run dev` برای اجرای توسعه یا `npm run build && npm start` برای اجرا.

## امنیت
- هرگز کلید service_role یا secret را در مرورگر یا مخزن قرار ندهید.
- فقط publishable/anon key در متغیرهای NEXT_PUBLIC مجاز است.
- RLS باید در تمام جدول‌های قابل دسترس فعال باشد.
- اطلاعات موکلان و اسناد واقعی را در GitHub یا logهای عمومی ذخیره نکنید.
- پیش از فعال‌سازی production، schema واقعی، عضویت دفتر، RLS و Storage ممیزی شوند.

## استقرار Render
Blueprint در `render.yaml` تعریف شده است. مقادیر Supabase باید به‌صورت Environment Variables در Render تنظیم شوند. ایجاد سرویس به انتخاب Workspace صحیح و تأیید تنظیمات نیاز دارد.

## ماژول‌ها
پرونده‌ها، موکلان، اسناد، مواعد، پژوهش حقوقی، امور مالی، گزارش‌ها، نقش‌ها و تنظیمات.
