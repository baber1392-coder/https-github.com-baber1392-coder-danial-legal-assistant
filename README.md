# دستیار جامع اختصاصی دانیال

سامانه فارسی، راست‌چین و واکنش‌گرا برای مدیریت اطلاعات دفتر وکالت در ایران.

## قابلیت‌های نسخه وب

- ورود با Supabase Auth و مسیر بازیابی گذرواژه
- داشبورد با آمار واقعی پرونده‌ها، موکلان، اسناد و مواعد
- ثبت، مشاهده و ویرایش پرونده‌ها، موکلان، مواعد، منابع پژوهشی و گردش‌های مالی
- بارگذاری اسناد در مخزن خصوصی Supabase Storage و دریافت لینک امضاشده کوتاه‌مدت
- ثبت مبنای قانونی، مرجع، شماره و وضعیت اعتبارسنجی منابع حقوقی
- تفکیک اطلاعات با office_id و سیاست‌های Row Level Security
- نمایش زمان مواعد بر مبنای منطقه زمانی Asia/Tehran
- نصب‌پذیری پایه به‌صورت PWA
- گفتگوی خصوصی با دستیار هوش مصنوعی مبتنی بر Google Gemini (طرح رایگان) یا OpenAI، ذخیره تاریخچه در Supabase و انتخاب اختیاری پرونده

## راه‌اندازی محلی

1. Node.js نسخه 20.9 یا بالاتر را نصب کنید.
2. فایل `.env.example` را به `.env.local` کپی کنید.
3. URL پروژه و کلید `sb_publishable_...` همان پروژه Supabase را در متغیرهای محیطی قرار دهید.
4. اجرا کنید:

```bash
npm install
npm run typecheck
npm run build
npm start
```

## دستیار هوشمند

ارائه‌دهنده پیشنهادی و پیش‌فرض، Google Gemini API با سهمیه رایگان است:

1. در [Groq Console](https://console.groq.com/keys) وارد شوید و یک API key بسازید.
2. در داشبورد Render، سرویس وب سامانه را باز کنید و به بخش Environment بروید.
3. متغیر محرمانه `GROQ_API_KEY` را با کلید ایجادشده ثبت کنید. کلید را در GitHub، کد یا گفتگوی عمومی قرار ندهید.
4. مقدار `GEMINI_MODEL` در صورت نیاز روی `openai/gpt-oss-120b` باشد و سپس سرویس را Deploy کنید.

اولویت انتخاب ارائه‌دهنده در وب‌اپ به‌ترتیب Groq، Gemini، OpenAI و در نهایت SambaNova است. اگر چند کلید ثبت شده باشد، انتخاب بر اساس همین ترتیب انجام می‌شود؛ این ترتیب به‌تنهایی failover خودکار هنگام اتمام سهمیه یک ارائه‌دهنده را تضمین نمی‌کند. کلیدها فقط در سرور استفاده می‌شوند. طرح رایگان Gemini سقف متغیر درخواست در دقیقه، توکن در دقیقه و درخواست روزانه دارد؛ سهمیه دقیق پروژه در AI Studio قابل مشاهده است و با عبور از آن خطای 429 دریافت می‌شود. دسترسی رایگان برای همه حساب‌ها و پروژه‌ها تضمین‌شده نیست.

**ملاحظه محرمانگی پرونده‌های وکالت:** طبق مستندات Google، محتوای طرح رایگان ممکن است برای بهبود محصولات Google استفاده شود. بنابراین پیش از ارسال اطلاعات هویتی، اسناد محرمانه، اسرار موکل یا داده‌های حساس پرونده، این شرط را لحاظ کنید و در صورت لزوم اطلاعات را بی‌نام‌سازی کنید یا از سرویس دارای تعهدات محرمانگی مناسب استفاده کنید. رایگان‌بودن API به معنای محرمانگی حرفه‌ای یا تضمین دسترس‌پذیری نیست.

تاریخچه گفتگوها در پایگاه داده دفتر ذخیره می‌شود. اطلاعات پرونده فقط وقتی به درخواست مدل افزوده می‌شود که کاربر همان پرونده را در رابط چت انتخاب کند. در حالت Gemini، گزینه جستجوی وب فعلاً به مدل ارسال نمی‌شود؛ برای پژوهش روزآمد، منابع و متن قوانین باید جداگانه بررسی شوند. گفتگوهای این وب‌اپ به‌صورت خودکار با تاریخچه حساب ChatGPT یا پیام‌های شما در چت‌های دیگر همگام نمی‌شوند.

## استقرار Render

Blueprint در `render.yaml` تعریف شده و برای شاخه `main` تنظیم شده است. متغیرهای محیطی عمومی Supabase باید در تنظیمات سرویس Render نیز ثبت باشند. کلید publishable قابل استفاده در مرورگر است؛ هرگز کلید `service_role` یا secret را در متغیرهای `NEXT_PUBLIC_*` قرار ندهید.

## داده و محرمانگی

- پایگاه داده عملیاتی این نسخه: `jwhyeohqolabcbuwhfon` در منطقه اروپای مرکزی.
- مخزن `case-documents` خصوصی است و سیاست Storage مسیر فایل را به شناسه دفتر محدود می‌کند.
- دسترسی واقعی به داده‌ها علاوه بر رابط کاربری در RLS کنترل می‌شود.
- داده پرونده یا موکل ساختگی در سامانه تولید نشده است.
- پیش از بارگذاری اسناد واقعی، مجوز کاربران، سیاست‌های دفتر و تنظیمات احراز هویت باید مطابق سیاست داخلی دفتر بازبینی شوند.

## محدودیت‌های فعلی

این نسخه هسته عملیاتی ثبت و مدیریت داده‌ها را فراهم می‌کند. دعوت و مدیریت نوشتاری اعضا، اتصال خودکار به ثنا/عدل‌ایران و دریافت خودکار ابلاغیه‌ها هنوز در این وب‌اپلیکیشن پیاده‌سازی نشده‌اند. دستیار هوشمند با ثبت کلید محرمانه Gemini یا OpenAI در Render فعال می‌شود. پژوهش حقوقی در این نسخه بر ثبت و نگهداری منابع استوار است؛ وجود پیوند منبع به‌تنهایی به معنای تأیید محتوای آن نیست.
