# دستیار جامع اختصاصی دانیال

سامانه فارسی، راست‌چین و واکنش‌گرا برای مدیریت اطلاعات دفتر وکالت در ایران.

## قابلیت‌های نسخه وب

- ورود با Supabase Auth و مسیر بازیابی گذرواژه
- داشبورد با آمار واقعی پرونده‌ها، موکلان، اسناد و مواعد
- ثبت، مشاهده و ویرایش پرونده‌ها، موکلان، مواعد، منابع پژوهشی و گردش‌های مالی
- بارگذاری اسناد در مخزن خصوصی Supabase Storage و دریافت لینک امضاشده کوتاه‌مدت
- ثبت مبنای قانونی، مرجع، شماره و وضعیت اعتبارسنجی منابع حقوقی
- تفکیک اطلاعات با office_id و سیاست‌های Row Level Security
- نمایش زمان مواعد بر مبنای منطقه زمانی Asia/Tehran
- نصب‌پذیری پایه به‌صورت PWA
- گفتگوی خصوصی با دستیار هوش مصنوعی مبتنی بر OpenAI Responses API، ذخیره تاریخچه در Supabase، انتخاب اختیاری پرونده و جستجوی اختیاری وب

## راه‌اندازی محلی

1. Node.js نسخه 20.9 یا بالاتر را نصب کنید.
2. فایل `.env.example` را به `.env.local` کپی کنید.
3. URL پروژه و کلید `sb_publishable_...` همان پروژه Supabase را در متغیرهای محیطی قرار دهید.
4. اجرا کنید:

```bash
npm install
npm run typecheck
npm run build
npm start
```

## دستیار هوشمند

برای فعال‌شدن پاسخ‌گویی در صفحه «دستیار هوشمند» باید متغیر محرمانه `OPENAI_API_KEY` در Environment سرویس Render ثبت شود. کلید را فقط در Render نگهداری کنید و هرگز آن را در کد، GitHub یا متغیر `NEXT_PUBLIC_*` قرار ندهید. مدل پیش‌فرض `gpt-6-astra` است و با `OPENAI_MODEL` قابل تغییر است. هزینه مصرف API مستقل از اشتراک ChatGPT است.

تاریخچه گفتگوها در پایگاه داده دفتر ذخیره می‌شود. پیام‌ها برای تولید پاسخ به OpenAI API ارسال می‌شوند؛ اطلاعات پرونده فقط وقتی به درخواست افزوده می‌شود که کاربر همان پرونده را در رابط چت انتخاب کند. گفتگوهای این وب‌اپ به‌صورت خودکار با تاریخچه حساب ChatGPT یا پیام‌های شما در چت‌های دیگر همگام نمی‌شوند.

## استقرار Render

Blueprint در `render.yaml` تعریف شده و برای شاخه `main` تنظیم شده است. متغیرهای محیطی عمومی Supabase باید در تنظیمات سرویس Render نیز ثبت باشند. کلید publishable قابل استفاده در مرورگر است؛ هرگز کلید `service_role` یا secret را در متغیرهای `NEXT_PUBLIC_*` قرار ندهید.

## داده و محرمانگی

- پایگاه داده عملیاتی این نسخه: `jwhyeohqolabcbuwhfon` در منطقه اروپای مرکزی.
- مخزن `case-documents` خصوصی است و سیاست Storage مسیر فایل را به شناسه دفتر محدود می‌کند.
- دسترسی واقعی به داده‌ها علاوه بر رابط کاربری در RLS کنترل می‌شود.
- داده پرونده یا موکل ساختگی در سامانه تولید نشده است.
- پیش از بارگذاری اسناد واقعی، مجوز کاربران، سیاست‌های دفتر و تنظیمات احراز هویت باید مطابق سیاست داخلی دفتر بازبینی شوند.

## محدودیت‌های فعلی

این نسخه هسته عملیاتی ثبت و مدیریت داده‌ها را فراهم می‌کند. دعوت و مدیریت نوشتاری اعضا، اتصال خودکار به ثنا/عدل‌ایران و دریافت خودکار ابلاغیه‌ها هنوز در این وب‌اپلیکیشن پیاده‌سازی نشده‌اند. دستیار هوشمند اضافه شده، اما پاسخ‌گویی عملی آن تا ثبت کلید محرمانه OpenAI در Render فعال نخواهد شد. پژوهش حقوقی در این نسخه بر ثبت و نگهداری منابع استوار است؛ وجود پیوند منبع به‌تنهایی به معنای تأیید محتوای آن نیست.
